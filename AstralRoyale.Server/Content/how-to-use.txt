1. Put your files in the Gamefiles folder + fingerprint.json
2. Run Patch.py
3. Copy the link from Patch.py. Example: "http://192.168.1.112:9340/"
4. Open server config.json and paste the link from Patch.py in "ContentURL": "Your_Link", and set boolean "ContentPatchEnabled" to true
5. Restart the server and have fun!
